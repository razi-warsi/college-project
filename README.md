# CodeVerse — Student Tech Hub

A responsive BSc IT student dashboard built with React + Vite.

## Features
## Features

- Responsive student dashboard and mobile navigation
- Dark / light theme toggle
- Course cards with progress indicators
- Searchable task list
- Add tasks and mark them complete
- Focus/streak UI and toast notifications
- React components and Lucide icons

## Tech Stack
- React 18
- Vite 6
- Supabase
- lucide-react

## Run Locally
1. Run `npm install`
2. Run `npm run dev`
3. Open the local URL shown in the terminal.
